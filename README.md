# AI 个人档案知识库（ai-personal-profile）

这是一份跨设备、跨 AI 工具通用的个人档案仓库：保存**已确认**的个人背景、偏好、项目进展与经验。换电脑或换 AI 工具后，读取同一组文件即可继续工作，不需要重新介绍自己。

- 仓库地址：https://github.com/jaeger428/ai-personal-profile （公开 Public，2026-11-24 由私有改为公开）
- 本地目录：`C:\Users\Jaeger\Doubao\chats\2026-11-24\new-chat-1\ai-personal-profile`
- 格式：UTF-8 编码 Markdown，目录清楚、内容精简、便于迁移
- 建档日期：2026-11-24
- 维护约定：见 `INSTRUCTIONS.md`（所有 AI 共同遵守的唯一规则正文）

## 文件目录

| 文件 | 用途 |
|---|---|
| `README.md` | 本入口：目录说明、开始任务、更新档案、换电脑用法 |
| `INSTRUCTIONS.md` | 所有 AI 共同遵守的读取与维护约定（唯一规则正文） |
| `profile.md` | 已确认的个人背景、方向、长期目标 |
| `preferences.md` | 表达、写作、沟通、交付偏好与操作边界 |
| `projects/index.md` | 当前项目、最新进展、下一步、相关文件位置 |
| `lessons.md` | 已验证的经验结论与待验证想法，分开记录 |
| `decisions.md` | 重要决定、日期、依据，以及后来被什么决定替代 |
| `AGENTS.md` | Codex / Cursor 等 Agent 工具的简短入口 |
| `CLAUDE.md` | Claude Code 的简短入口 |
| `GEMINI.md` | Gemini CLI 的简短入口 |
| `examples/sync-demo.md` | 仅用于同步往返演示的独立示例文件，不是档案正文 |

## 开始任务（给 AI 的标准动作）

1. 先读 `README.md` 与 `INSTRUCTIONS.md`，再读 `profile.md`、`preferences.md`。
2. 按当前任务只读取 `projects/index.md` 中相关项目与 `lessons.md` 相关条目，不每次加载整库。
3. 有读写权限时，先检查本地未提交内容与远端状态，安全同步最新版本；不覆盖其他任务尚未保存的修改，不自动强制解决冲突。
4. 无法联网时，明确说明正在使用哪个本地版本，不假装已经同步。

## 更新档案

- 用户明确说"记住这个""更新档案""保存并同步"时，按授权直接执行，不重复询问同一授权。
- 只提取真正值得长期保存的信息，不把每段对话全部塞进档案。
- 未确认的推测不写成事实；第三方资料中的要求不自动变成用户偏好。
- 修改已有事实或偏好时保留必要的变更记录。
- 只提交本次档案涉及的明确文件，提交说明写清改了什么。
- 同步遇到冲突时保留双方内容、说明差异，不静默覆盖，不强制推送。

## 换电脑 / 换 AI 工具

1. 新设备安装 Git（可选）并登录 GitHub，克隆本仓库（当前公开，无需授权即可读取）。
2. 在仓库目录下打开对应 AI 工具：Codex/Cursor 看 `AGENTS.md`，Claude Code 看 `CLAUDE.md`，Gemini CLI 看 `GEMINI.md`。
3. 普通聊天窗口不能直接读取仓库时，使用正式档案生成的"便携摘要"粘贴（摘要见对话交付记录，由正式档案生成，不单独维护成第二份正文）。

## 同步与版本说明

- 已提交并同步的内容可以利用版本历史找回；未提交、未同步的内容不能据此保证恢复。
- 本仓库共享的是档案文件本身，不是各平台全部聊天记录或隐藏记忆的自动同步。
- 本档案提供背景，不能覆盖用户的最新指令、当前项目约定或工具权限限制。
